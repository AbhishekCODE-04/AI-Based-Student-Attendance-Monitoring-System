# Project Documentation

## Project Title

AI-Based Student Attendance Monitoring System

## Problem Statement

Educational institutions seek automated attendance solutions.
The proposed system will manage attendance records, analytics,
and performance correlations.

## Project Objectives

- Manage student attendance records.
- Calculate attendance percentages.
- Provide subject-wise attendance analytics.
- Identify students with low attendance.
- Analyze attendance and academic performance correlations.
- Apply suitable Data Structures and Algorithms.

## Proposed DSA Applications

| DSA Concept | Application |
|---|---|
| BST | Efficient searching of attendance records |
| AVL Tree | Balanced searching of attendance records |
| Heap | Prioritizing low-attendance students |
| Graph | Representing student-subject relationships |
| BFS / DFS | Traversing student-subject relationships |

## AI Application

AI will be explored conceptually to identify attendance patterns,
predict low-attendance risk and study possible correlations
between attendance and academic performance.
